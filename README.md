# franklin-digital-bulletin-board
Files:
1. index.html — complete dashboard with the logo embedded directly.
2. franklin_logo_v5_all_white_details.png — high-resolution transparent logo used in Version 5.

V5 logo update:
- Uses the newly supplied Franklin Academy logo.
- Changes the large right-side FRANKLIN ACADEMY wordmark to pure white.
- Changes every previously black logo detail to pure white, including the atom, book, banner text, outlines, and ivy details.
- Preserves the original burgundy and navy crest.
- Keeps a transparent background with no white rectangle.
- Displays the logo slightly larger for better TV readability.

To preview:
Open index.html in a normal web browser. Internet access is required for the live Google Calendar and Irvine weather.

For the Samsung TV:
Upload the files to the selected static host, then open the dashboard URL in the Samsung TV browser.
